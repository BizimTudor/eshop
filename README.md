# EShop API

A Spring Boot e-commerce backend built to learn backend development.

## Tech stack
Java 21, Spring Boot 3.5, Spring Data JPA, H2 (PostgreSQL planned), Gradle

## Run
./gradlew bootRun

API docs: http://localhost:8080/swagger-ui.html

## Roadmap
- [x] Phase 1: Product CRUD, validation, pagination, error handling
- [ ] Phase 2: PostgreSQL, Flyway, orders, transactions
- [ ] Phase 3: Spring Security + JWT
- [ ] Phase 4+: caching, messaging, testing, Docker, CI
